## 1. 全局隐性约束（改任何页面前先看这 5 条）

| # | 约束 | 说明 |
|---|------|------|
| 1 | **viewport meta 必须存在** | `<meta name="viewport" content="width=device-width, initial-scale=1.0, maximum-scale=1.0, user-scalable=no">`，否则手机自动缩放错位 |
| 2 | **断点统一用 768px** | `window.innerWidth <= 768`，Element Plus 栅格也是 768 分界 |
| 3 | **Element Plus 布局用 v-if 不用 v-show** | v-show 在 display:none 时组件内部 ref 会 null |
| 4 | **isMobile 检测加 resize 监听 + onBeforeUnmount 清理** | 只写 onMounted 一次不够 |
| 5 | **Vue 3 template 自动解包 ref** | template 里写 `{{ profile?.name }}` 不是 `profile.value?.name` |

### isMobile 标准模板

```typescript
const isMobile = ref(false)
const checkMobile = () => { isMobile.value = window.innerWidth <= 768 }
onMounted(() => { checkMobile(); window.addEventListener('resize', checkMobile) })
onBeforeUnmount(() => window.removeEventListener('resize', checkMobile))
```

## 4. ⭐ 分页最佳实践（2026-10-22 踩坑确认）

### ❌ 错误写法

```vue
<el-pagination @current-change="fetchList" />
<script>
const fetchList = async () => {
  const params = { pageNum: query.pageNum, ... }  // ⚠️ 读到的还是旧值
}
</script>
```

某些 Element Plus 版本中 `@current-change` 事件先于 `v-model:page-num` 的 `update` emit 执行，fetchList() 里读到的 pageNum 还是旧值，翻页永远请求 page1。

### ✅ 正确写法（显式回调，先赋值后请求）

```vue
<el-pagination
  v-model:page-num="query.pageNum"
  v-model:page-size="query.pageSize"
  @current-change="handlePageChange"
  @size-change="handleSizeChange"
/>
<script>
const query = reactive({ pageNum: 1, pageSize: 10, status: '', keyword: '', timeRange: [] })

// ⭐ 显式回调
const handlePageChange = (page) => {
  query.pageNum = page   // ① 先强制更新
  fetchList()            // ② 再请求（此时读 query.pageNum 一定是新值）
}
const handleSizeChange = (size) => {
  query.pageSize = size
  query.pageNum = 1      // 改条数必须重置第 1 页
  fetchList()
}
const handleSearch = () => { query.pageNum = 1; fetchList() }
const resetQuery = () => { query.keyword = ''; query.status = ''; query.timeRange = []; query.pageNum = 1; fetchList() }

const fetchList = async () => {
  const params = { pageNum: query.pageNum, pageSize: query.pageSize }
  if (query.status) params.status = query.status
  if (query.keyword?.trim()) params.keyword = query.keyword.trim()
  if (query.timeRange?.length === 2) {
    params.startTime = query.timeRange[0] + ' 00:00:00'
    params.endTime   = query.timeRange[1] + ' 23:59:59'
  }
  const res = await api.getList(params)
  list.value = res.data?.records || []
  total.value = res.data?.total || 0
}
</script>
```

### 适用场景

| 场景 | 关键动作 | 重置到第 1 页？ |
|---|---|---|
| 翻页 | handlePageChange(page) | ❌ 不重置 |
| 改每页条数 | handleSizeChange(size) | ✅ 必须重置 |
| 点击搜索 | handleSearch() | ✅ 必须重置 |
| 点击重置 | resetQuery() | ✅ 必须重置 |
| el-select 自动搜索 | 绑定回调里重置 pageNum=1 | ✅ 必须重置 |

### 跨页连续序号

```vue
<el-table-column
  type="index" label="序号" width="70"
  :index="(i) => (query.pageNum - 1) * query.pageSize + i + 1"
/>
```

el-table 原生 `type="index"` 默认不跨页连续，用函数形式手动计算。

### 后端分页接口规范

```java
@GetMapping("/list")
public R<Page<Xxx>> list(
        @RequestParam(defaultValue = "1") Integer pageNum,
        @RequestParam(defaultValue = "10") Integer pageSize,
        @RequestParam(required = false) String status,
        @RequestParam(required = false) String keyword,
        @RequestParam(required = false) String startTime,
        @RequestParam(required = false) String endTime) {
    return R.ok(service.page(pageNum, pageSize, ...));
}
```

Service 实现用 MyBatis-Plus LambdaQueryWrapper：

```java
public Page<Xxx> page(Integer pageNum, Integer pageSize, Long userId,
                     String status, String keyword, String startTime, String endTime) {
    LambdaQueryWrapper<Xxx> w = new LambdaQueryWrapper<>();
    w.eq(Xxx::getCreateBy, userId);
    if (status != null && !status.isEmpty()) w.eq(Xxx::getStatus, status);
    if (keyword != null && !keyword.isEmpty()) w.like(Xxx::getName, keyword.trim());
    if (startTime != null && !startTime.isEmpty()) w.ge(Xxx::getCreateTime, startTime);
    if (endTime != null && !endTime.isEmpty()) w.le(Xxx::getCreateTime, endTime);
    w.orderByDesc(Xxx::getCreateTime);
    return this.page(new Page<>(pageNum, pageSize), w);
}
```

> ⚠️ 前提：TenantMybatisPlusConfig 里已注册 PaginationInnerInterceptor，否则 this.page() 返回全量数据不分页。

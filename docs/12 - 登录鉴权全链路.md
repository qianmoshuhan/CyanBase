# 鉴权全链路说明
本底座采用**双登录通道 + JWT过滤器鉴权 + MP租户拦截器数据隔离**架构

## 1. 登录通道
1. 平台超管登录：POST /auth/login
   入参：username、password、credentialKey
   Token claims：userId、userName、roles，不携带tenantId
2. 租户用户登录：POST /tenant-auth/login
   入参：phone、password、credentialKey、tenantId（选填）
   多租户匹配分支：手机号命中多个租户账号时，前端选择tenantId后二次提交
   Token claims：userId、userName、roles、tenantId

登录成功统一后置：写入登录日志、在线用户记录、缓存refreshToken；登录失败返回对应错误码

## 2. 请求鉴权（JwtAuthenticationFilter）
1. 请求头读取token
2. 校验Redis黑名单、踢下线标记
3. JWT验签、有效期校验
4. 解析claims，加载用户权限，组装LoginUser
5. 构造Authentication存入SecurityContextHolder
6. 放行链路，请求结束清理上下文

## 3. 租户数据隔离（CustomTenantHandler + TenantLineInterceptor）
三级降级获取tenantId：
① SecurityContext LoginUser.sysUser.tenantId
② SecurityContext LoginUser.tenantId
③ 解析请求头JWT
- 超管：tenantId为空，跳过租户条件拼接
- 租户用户：自动追加 tenant_id = {当前租户}

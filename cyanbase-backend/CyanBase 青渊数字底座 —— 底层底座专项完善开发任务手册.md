## 四、详细开发规范（AI 逐条执行）

### 4.1 全局错误码规范

1. 新建统一枚举类 `ResultCodeEnum`

2. 错误码分层：
   
   - 系统级：10000-19999
   - 认证权限：20000-29999
   - 用户部门角色：30000-39999
   - 字典配置：40000-49999
   - 文件模块：50000-59999
   - 定时任务：60000-69999
   - 消息公告：70000-79999
   - 流程表单：80000-89999

3. 所有异常 **禁止硬编码字符串**，必须走枚举

### 4.2 全局异常处理规范

1. 分层异常：
   
   - 认证异常
   - 权限异常
   - 参数异常
   - 业务异常
   - 系统异常

2. 全局异常处理器统一捕获，**无遗漏**

3. 所有异常统一返回 `R.fail(错误码)`

4. 异常自动日志打印、异常堆栈可控输出

### 4.3 接口安全规范

1. 全局请求参数非空、格式、长度校验
2. 重复请求拦截（5 秒防重）
3. 非法字符、SQL 特殊字符过滤
4. 敏感参数脱敏

### 4.4 权限加固规范

1. 新增自定义权限注解 `@RequiresPerm("system:user:list")`
2. 实现 **按钮级接口权限**
3. 实现 **部门数据权限隔离**
4. 超级管理员自动放行所有权限

### 4.5 Redis 缓存规范

1. 统一缓存前缀：`cyanbase:`
2. 字典缓存、系统配置缓存默认永久缓存
3. 用户信息缓存 1 小时
4. 所有缓存支持手动刷新、清空接口

### 4.6 日志规范

1. 操作日志 AOP **自动记录**：模块、操作、IP、用户、参数、结果
2. 登录日志记录：成功 / 失败、IP、设备、时间
3. 异常日志统一入库与控制台输出
4. 日志保留策略可配置

### 4.7 文件模块规范

1. 默认本地存储，路径可配置
2. 限制文件大小、后缀、MIME 类型
3. 文件访问必须鉴权
4. 上传记录入库、可追溯

### 4.8 定时任务规范

1. 支持 CRON 表达式配置
2. 支持立即执行、暂停、恢复
3. 任务唯一锁，防止并发重复执行
4. 任务执行日志完整记录

### 4.9 消息通知规范

1. 站内消息区分：系统消息、公告消息
2. 未读数量统计全局实时
3. 支持全部已读、单条已读
4. 公告支持置顶、过期时间

### 4.10 前端 UI 规范

1. 全站统一 **稳重、严谨、政企商务风格**
2. 主色调：深蓝基底、浅灰辅助、深灰文字
3. 禁止亮色、艳丽、花哨组件样式
4. 所有字典字段自动翻译
5. 所有按钮根据权限自动显隐
